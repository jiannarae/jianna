# Hypotenuse Calculator

## This program calculates the length of the hypotenuse of a right triangle using the lengths of the two shorter sides and a math library

## How to Run
1. Open the program file in VS Code, Replit, or Google Colab.
2. Run the Program.
3. Enter the length of side a.
4. Enter the length of side b.
5. Check the hypotenuse displayed on the screen.

## Input Needed
- Side a
- Side b

## Sample Output
Enter the length of side a: 3

Enter the length of side b: 4

The distance between the two points is: 5.00
